# BodyBuddy v0.2 - Xcode Setup Guide

This guide explains how to complete the v0.2 setup in Xcode for HealthKit and watchOS integration.

## Step 1: Add Service Files to iOS Target

The following files were created but need to be added to the Xcode project:

1. Open `BodyBuddy.xcodeproj` in Xcode
2. In the Project Navigator, right-click on `BodyBuddy` folder
3. Select "Add Files to 'BodyBuddy'..."
4. Navigate to and select the `Services` folder
5. Ensure "Copy items if needed" is **unchecked**
6. Ensure "Create groups" is selected
7. Ensure "BodyBuddy" target is checked
8. Click "Add"

This adds these files:
- `Services/HealthKitManager.swift`
- `Services/CalorieEstimator.swift`
- `Services/WatchConnectivityManager.swift`

## Step 2: Add HealthKit Capability

1. Select the project in the Navigator
2. Select the "BodyBuddy" target
3. Go to "Signing & Capabilities" tab
4. Click "+ Capability"
5. Search for "HealthKit" and add it
6. In the HealthKit capability, check "Background Delivery" (optional)

## Step 3: Add HealthKit Usage Descriptions

1. Select the "BodyBuddy" target
2. Go to "Info" tab
3. Add these keys under "Custom iOS Target Properties":

| Key | Type | Value |
|-----|------|-------|
| `NSHealthShareUsageDescription` | String | BodyBuddy reads your weight and age to calculate accurate calories burned during workouts. |
| `NSHealthUpdateUsageDescription` | String | BodyBuddy saves your completed workouts to the Health app to track your fitness progress and close your Activity rings. |

**Alternative:** In Build Settings, search for "Info.plist" and add:
- `INFOPLIST_KEY_NSHealthShareUsageDescription = "..."`
- `INFOPLIST_KEY_NSHealthUpdateUsageDescription = "..."`

## Step 4: Create watchOS Target

1. File → New → Target
2. Select "watchOS" → "App"
3. Configure:
   - Product Name: `BodyBuddyWatch`
   - Organization Identifier: (same as iOS app)
   - Interface: SwiftUI
   - Life Cycle: SwiftUI App
   - Language: Swift
   - **Uncheck** "Include Notification Scene"
   - **Uncheck** "Include Complication"
4. Click "Finish"
5. When prompted to activate the scheme, click "Activate"

## Step 5: Configure watchOS Target

### 5.1 Add BodyBuddyCore Dependency

1. Select the project in Navigator
2. Select "BodyBuddyWatch" target
3. Go to "General" tab
4. Under "Frameworks, Libraries, and Embedded Content"
5. Click "+"
6. Select "BodyBuddyCore" from the workspace

### 5.2 Add HealthKit Capability

1. Select "BodyBuddyWatch" target
2. Go to "Signing & Capabilities"
3. Add "HealthKit" capability
4. Check "Workout Processing" background mode

### 5.3 Replace Generated Files

Delete the auto-generated files in the BodyBuddyWatch group and add the prepared files:

1. Delete auto-generated `BodyBuddyWatchApp.swift` and `ContentView.swift`
2. Right-click on "BodyBuddyWatch" group
3. Select "Add Files to 'BodyBuddy'..."
4. Navigate to `BodyBuddyWatch/` folder
5. Select all Swift files
6. Ensure "BodyBuddyWatch" target is checked
7. Click "Add"

Files to add:
- `BodyBuddyWatchApp.swift`
- `ContentView.swift`
- `ViewModels/WatchAppState.swift`
- `Services/WatchConnectivityService.swift`
- `Views/WatchTodayView.swift`
- `Views/WatchWorkoutPlayerView.swift`

## Step 6: Build and Test

### iOS App
1. Select "BodyBuddy" scheme
2. Select an iOS simulator or device
3. Press ⌘R to build and run
4. Complete a workout to test HealthKit integration

### watchOS App
1. Select "BodyBuddyWatch" scheme
2. Ensure paired iOS simulator is running
3. Press ⌘R to build and run
4. Test workout sync between iPhone and Watch

## Verification Checklist

- [ ] iOS app builds without errors
- [ ] HealthKit permission prompt appears when finishing first workout
- [ ] Completed workout appears in Apple Health app
- [ ] Activity rings update after workout
- [ ] watchOS app builds without errors
- [ ] Watch displays "iPhone not reachable" when disconnected
- [ ] Watch syncs today's workout from iPhone
- [ ] Set completion on Watch updates iPhone
- [ ] Finishing workout on Watch saves to HealthKit

## Troubleshooting

### "Cannot find 'HealthKitManager' in scope"
- Ensure Services folder is added to the project
- Ensure files are included in the BodyBuddy target (check File Inspector)

### "WCSession.default" not working
- WatchConnectivity requires real devices for full testing
- Simulators have limited WatchConnectivity support

### HealthKit not showing in Health app
- Ensure HealthKit capability is added
- Ensure usage descriptions are set
- Test on physical device (simulators don't support HealthKit)
